Scope: edit your own posts (caption and Nursery flag). OpenAPI-first. All management stays in the pet-profile post modal per the placement rule — the feed and post/[id] remain view-only. No archive, no pet editing, no deletion changes.

Preservation clause: the pet-profile modal's existing behavior (full photo, caption, delete card with its confirm flow, dismissal paths incl. Android back) is preserved exactly; enumerate before modifying.

API: PATCH /posts/{id} — 403 unless the caller owns the post's pet; accepts optional caption (may be set, changed, or cleared to null) and isNursery boolean; returns the updated post. 404 for unknown IDs.
UI: the modal gains a quiet Edit post row above the delete card (pencil icon, standard foreground — not destructive styling). Tapping switches the modal's lower section into edit mode inline: caption input prefilled (multiline, same styling as the Add form's caption field), Nursery toggle reflecting current state, Cancel / Save side-by-side (no Alert.alert). Save shows a spinner, disables both buttons while pending; on success returns to view mode with updated content and invalidates the pet query, Home feed, and Nursery feed (a Nursery-flag change must move the post in/out of the Nursery grid immediately). Cancel discards changes and restores view mode. Edit and delete confirm states are mutually exclusive — opening one closes the other. All edit state resets on every modal dismissal path.
Non-owners see no edit row. Apply identically to web, iOS, and Android. No react-native-reanimated imports.

Acceptance test (physical iPhone + web): Editing a caption updates it in the modal, the feed overlay, and the post detail after refresh; clearing a caption makes the feed show "View full photo ↗"; toggling Nursery on moves the post into the Nursery grid (and off removes it); Cancel changes nothing; non-owners and Finn's posts show no edit row. Golden path unbroken: sign in → feed loads → boop persists → post flow works → sign out. pnpm run typecheck clean.
