GOAL: Extend the existing report system to accept a "user" target type, alongside the existing "post" and "comment" targets.
1. Add a way to report a user directly from their profile (reuse the existing ReportFlow.tsx component/pattern — add "user" as a valid target type it can submit, alongside post/comment).
2. Extend POST /api/reports to accept and correctly store a user-target report (not just post/comment).
3. The admin Reports screen should correctly display user-targeted reports alongside post/comment ones, and the existing dismiss/suspend actions should work against a user-targeted report (suspend already operates on a user account, so this should mostly reuse existing logic — "hide" doesn't apply to a user-target report the same way it does content, so confirm/adjust that action's behavior appropriately for this target type, e.g. hide may not be a valid action for a user-target report).
