CONTEXT: Two unrelated changes in one pass.

1. Blur upgrade for the crop fill. Currently, when a post's photo doesn't fully cover its frame, a flat sampled color fills the empty space (already shipped, works correctly). We want to upgrade this to look like a blurred extension of the photo — but only on STATIC render surfaces (feed, post detail, share cards), not the live Adjust/crop editor, which must stay on the cheap solid-color fill for gesture performance.

2. Spacing fix: in the pet-info chrome row (where the paw icon and "following" text appear), the gap between the paw icon and the word "following" is too tight/crowded. Increase that spacing slightly.

GOAL:

Part 1 — Blur, via a tiny-thumbnail-stretch technique (not a true blur filter, to avoid platform-specific blur API differences between web and native):
1. At post time (same moment crop_fill_color is currently sampled), also generate a very small thumbnail of the photo (e.g. ~24×24px) and store it — a data URI is fine given the tiny size, in a new column (e.g. crop_fill_thumb).
2. On the static render surfaces (feed, post detail, share card web + native paths), when a fill is needed: render this tiny thumbnail stretched/scaled to cover the fill area (object-fit: cover or equivalent), UNDER the actual photo. 1. Increase the gap between the paw icon and the "following" text in the pet-info chrome row. A modest increment (e.g. a few pixels) is sufficient — this is a minor legibility/comfort fix, not a redesign.
